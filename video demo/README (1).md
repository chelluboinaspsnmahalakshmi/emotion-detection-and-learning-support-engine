### 🎬 What's included in the Demo:
In this video demonstration, I walk through the core features of the application from start to finish:
1. **Server Initialization:** Starting the local Streamlit server (`localhost:8501`).
2. **Secure Access:** Logging into the application securely using the SQLite authentication system.
3. **Emotion Inference:** Providing a sample student problem as text input to the engine.
4. **AI Generation:** Showing the real-time processing where the BiLSTM/BERT model detects the emotion, and the Google Gemini API generates the customized empathetic coaching response.
5. **Analytics Dashboard:** Viewing the interactive Plotly data visualizations that dynamically track the session history.
